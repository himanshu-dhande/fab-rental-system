# fab-rental-system
Online Clothing Rental System developed using web technologies to provide outfit rental, booking, payment, vendor management, and delivery tracking features.

# FAB Rental – Online Clothing Rental System

FAB Rental is an online platform that allows users to rent stylish and trendy clothes for different occasions instead of purchasing them.

The system provides an affordable, eco-friendly, and convenient clothing rental experience while helping reduce fashion waste.

---

## 📌 Features

### User Module
- User Registration & Login
- Browse outfits
- Search and filter products
- Rent clothing items
- Payment processing
- Delivery tracking
- Return management

### Vendor Module
- Upload clothing products
- Manage inventory
- Accept or reject bookings

### Admin Module
- Manage users and vendors
- Monitor transactions
- Generate reports

### Additional Features
- Secure payment integration
- Responsive design
- Customer reviews and ratings
- Wishlist/Favorites
